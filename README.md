## English

### Overview

Qaf is a free, offline-first reading and search application for classical and modern Persian poetry. The complete reference database ships inside the app, so every poet, work, poem and verse is available without an internet connection, with no account and no tracking.

The name refers to the letter Qaf, the mythical mountain of Persian literature.

### Features

**Browsing**
- Home screen with quick access to poets and works, and a shortcut back to what you were reading.
- Poets directory with a detail page for each poet, including portraits.
- Works directory with a hierarchical view that follows the structure of each book (sections, chapters, poems).
- Poem reader with previous and next navigation and a distraction-free zen reading mode.

**Search**
- Global search across poets, works, poems and verses.
- Every word of a query must match, in any order.
- Normalization of Persian and Arabic character variants (for example the different forms of ye, kaf and alef), Persian, Arabic and Latin digits, half-spaces, and diacritics, so a search finds the text regardless of how it was typed.
- Results are ranked: exact matches first, then prefix matches, word-start matches and finally partial matches.
- Filters by century, poet and city.

**Personal library**
- Bookmarks for poets, works, poems and individual verses, organized in one place.
- Reading history that can be cleared at any time.
- Copy a single verse or a complete poem to the clipboard.

**Experience**
- Light and dark themes, following the system setting by default.
- Right-to-left interface designed for Persian typography, using the Arad typeface.
- All user data (bookmarks, history, theme) stays on the device.

### Privacy

The application code makes no network requests and includes no analytics or advertising. Reading history and bookmarks are stored locally on the device and never leave it.

### Technology

| Layer | Details |
| --- | --- |
| Application | Vanilla HTML, CSS and JavaScript (`capacitor-app/www/index.html`) |
| Native shell | [Capacitor](https://capacitorjs.com) 8, Android |
| Database | SQLite through [`@capacitor-community/sqlite`](https://github.com/capacitor-community/sqlite), installed from the bundled asset on first launch |
| Search | SQL `GLOB` matching with character-class normalization and ranked ordering |

### Repository structure

```
qaf_app/
  capacitor-app/
    www/                 Web application (index.html, fonts, poet images, database asset)
    android/             Native Android project generated by Capacitor
    assets/              Source artwork for the app icon and splash screen
    capacitor.config.json
    package.json
  .github/workflows/     Manual CI workflow that builds a debug APK
  deploy-to-drive.sh     Development helper: build and upload a debug APK with rclone
  LICENSE
```

The database asset (`capacitor-app/www/assets/databases/qaf.db.gz`) is stored with [Git LFS](https://git-lfs.com). Cloning with Git LFS installed is required to obtain it. The "Download ZIP" button on GitHub does not include it.

### Installation

Download the latest APK from the [Releases](https://github.com/thecurumo/qaf_app/releases) page and open it on an Android device. You may need to allow installation from unknown sources for your browser or file manager.

### Building from source

Requirements: Git with Git LFS, Node.js 22 or newer, JDK 21, and the Android SDK.

```bash
git lfs install
git clone https://github.com/thecurumo/qaf_app.git
cd qaf_app/capacitor-app

npm ci
npx cap sync android

cd android
./gradlew assembleDebug
```

The APK is written to `capacitor-app/android/app/build/outputs/apk/debug/app-debug.apk`. To work on the native project in Android Studio, run `npx cap open android` from `capacitor-app`.

After changing anything inside `www/`, run `npx cap sync android` before rebuilding.

## فارسی

### معرفی

«قاف» یک برنامهٔ رایگان و آفلاین برای خواندن و جست‌وجوی شعر پارسی است. پایگاه داده کامل درون خود برنامه قرار دارد؛ بنابراین تمام سخنوران، آثار، اشعار و ابیات بدون نیاز به اینترنت، بدون حساب کاربری و بدون هیچ‌گونه ردیابی در دسترس هستند.

نام «قاف» یادآور کوه قاف، کوه اسطوره‌ای ادبیات پارسی است.

### ویژگی‌ها

**مرور**
- صفحهٔ اصلی با دسترسی سریع به سخنوران و آثار، و بازگشت به آخرین متنی که می‌خواندید.
- فهرست سخنوران با صفحهٔ اختصاصی برای هر سخنور، همراه با تصویر.
- فهرست آثار با نمایش سلسله‌مراتبی که ساختار هر کتاب (بخش‌ها، فصل‌ها و اشعار) را دنبال می‌کند.
- خواننده شعر با پیمایش قبلی و بعدی و حالت مطالعهٔ آرام (Zen) برای خواندن بدون حواس‌پرتی.

**جست‌وجو**
- جست‌وجوی سراسری در سخنوران، آثار، اشعار و ابیات.
- تمام واژه‌های عبارت جست‌وجو باید در نتیجه باشند، با هر ترتیبی.
- یکسان‌سازی شکل‌های فارسی و عربی حروف (مانند انواع «ی»، «ک» و «ا»)، ارقام فارسی، عربی و لاتین، نیم‌فاصله و اعراب؛ بنابراین متن مورد نظر شما صرف‌نظر از شیوهٔ تایپ پیدا می‌شود.
- رتبه‌بندی نتایج: ابتدا تطابق کامل، سپس آغاز عبارت، آغاز واژه و در پایان تطابق جزئی.
- فیلتر بر اساس قرن، سخنور و شهر.

**کتابخانهٔ شخصی**
- نشان‌کردن سخنوران، آثار، اشعار و ابیات و مدیریت آن‌ها در یک صفحه.
- تاریخچهٔ خوانش که هر زمان می‌توان آن را پاک کرد.
- کپی یک بیت یا کل شعر در کلیپ‌بورد.

**تجربهٔ کاربری**
- پوستهٔ روشن و تیره، به‌صورت پیش‌فرض مطابق تنظیم سیستم.
- رابط راست‌به‌چپ، طراحی‌شده برای حروف‌چینی فارسی با فونت آراد.
- تمام داده‌های کاربر (نشان‌ها، تاریخچه و پوسته) روی دستگاه می‌ماند.

### حریم خصوصی

کد برنامه هیچ درخواست شبکه‌ای ارسال نمی‌کند و شامل ابزار تحلیل یا تبلیغات نیست. تاریخچه و نشان‌ها فقط روی دستگاه شما ذخیره می‌شوند و از آن خارج نمی‌شوند.

### منبع داده و قدردانی

پایگاه داده ادبی این برنامه بر پایهٔ داده‌های آزاد منتشرشده و آرشیوشده توسط [گنجور](https://ganjoor.net) تهیه شده است. قاف بدون سال‌ها تلاش گنجور ممکن نبود؛ با این حال قاف وابسته به گنجور نیست و از سوی آن تأیید نشده است. متن‌ها همچنان تابع شرایط و ارجاعاتی هستند که گنجور و منابع اصلی آن تعیین کرده‌اند.

تصاویر سخنوران توسط نگارندهٔ پروژه ساخته شده است. فونت آراد با مجوز SIL Open Font License 1.1 استفاده شده است. قاف همچنین از Capacitor و افزونهٔ SQLite جامعهٔ Capacitor استفاده می‌کند که هر یک تابع مجوز خود هستند.
